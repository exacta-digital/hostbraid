# Security policy

HostBraid will handle hosting API credentials, SSH coordinates, database exports, and site files.
Please do not report vulnerabilities in a public issue.

Until a dedicated security address and repository advisory process are published, contact It's Ed
through [itsed.se](https://itsed.se) and request a private security channel. Do not include tokens,
passwords, signed download URLs, customer data, or working exploit payloads in the initial message.

Security reports should include affected versions, impact, reproduction conditions, and any safe
mitigation you have identified.
